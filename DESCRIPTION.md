# Report description (Week 2 task)

This report documents a complete data collection, cleaning and preprocessing pipeline for logistics analysis, built in Python with pandas, NumPy and scikit-learn. Because the task asks for a simulated data collection, I created a shipment dataset of 4,732 records and 17 fields, modelled on public supply-chain datasets such as the Kaggle DataCo Smart Supply Chain data. The data is synthetic and seeded, so every result can be reproduced, and realistic quality problems were injected on purpose: 1,688 missing values, 138 duplicate rows, 13 spellings of four transport modes, currency stored as text, impossible values (negative weights, zero distances, deliveries before shipping) and extreme outliers.

The report explains each step: what the problem is, why a particular technique was chosen, how it was coded, and how it changes later analysis. Labels and data types were standardised first, then duplicates removed and invalid values repaired. Missing values were filled with group-wise medians by transport mode, with an explicit "Unknown" category for carriers. Outliers were detected with the IQR rule and Z-scores and winsorised rather than deleted. I also found that the plain IQR rule wrongly flags 410 natural heavy shipments in right-skewed weight data, so for weight and cost the fences were calculated on a log scale, which reduced this to 92. Finally, features such as delay days and cost per kilometre were engineered, and the data was scaled with Min-Max and Z-score methods, log-transformed and one-hot encoded.

The results are verified with automatic checks and a before-and-after comparison: duplicates fell from 138 to 0, transport labels from 13 to 4, and the average shipping cost moved from $554.8 to $144.1 once extreme records stopped distorting it. The reflection section explains how data quality affects budgets, carrier comparisons, forecasting and inventory decisions in logistics, and lists limitations, including that the data is simulated. The full code, datasets, charts and README are provided in the GitHub project.
